# Retentia — Frontend

> An interactive web application designed to enhance knowledge retention through concept selection, active recall, and spaced repetition.

---

## About the Project

**Retentia** is an open-source learning platform built to help users retain concepts efficiently. Built with modern web technologies, the frontend delivers a fast, responsive, and intuitive interface for navigating concepts, tracking study sessions, and engaging with active recall exercises.

---

## Getting Started

### Prerequisites

Make sure you have the following installed on your machine:
- **Node.js** (v18.0.0 or higher recommended)
- **npm**, **yarn**, **pnpm**, or **bun**

### Installation

1. Clone the repository
2. Install dependencies:

    ```bash
    npm run dev
    # or
    yarn dev
    # or
    pnpm dev
    # or
    bun dev
    ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
